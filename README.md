# Список услуг и детали

Учебный проект, демонстрирующий работу с React Router, Redux, Redux-Saga и REST API
Приложение показывает список услуг и страницу с подробной информацией об услуге

## Стек технологий
- React (Vite)
- React Router DOM
- Redux + React-Redux
- Redux-Saga
